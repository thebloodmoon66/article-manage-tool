## 直接使用

下载并解压 [论文投稿管理助手-0.1.2.zip](./论文投稿管理助手-0.1.2.zip)，保留解压后的完整文件夹，然后运行其中的 `论文投稿管理助手.exe`。

当前版本：**0.1.2**。左侧论文列表改为按像素滚动，展开栏目的内容可以在列表顶部或底部部分显示，方便连续浏览。

软件仅在尚未设置数据目录，或原目录已经失效时让用户选择。选择结果记录在便携版程序文件夹内的 `数据目录位置.txt`，之后启动会自动沿用，不会写入 Windows 用户配置目录。数据目录位于便携程序文件夹内部时自动保存为相对路径，整包换盘或换电脑后仍能识别。点击软件右上角带下划线的“数据目录”即可重新选择并自动重启；切换不会自动搬移原目录数据。也可以用 `--data-dir "路径"` 启动参数明确指定并保存目录。

第一次使用某个空数据文件夹时，软件会自动载入内置的 `期刊选择.xlsx` 资料；之后也可以在“期刊资料查询及修改”页继续导入其他 XLSX。

其中：

- `paper-submissions.db`：SQLite 数据库；
- `attachments/`：软件复制并管理的论文和自定义附件；
- `backups/`：期刊导入或修改前的数据库快照，自动保留最近三代。

SQLite 工作文件、附件暂存区和附件回收区同样只会出现在所选数据文件夹内。软件不会在 `%LOCALAPPDATA%` 等用户目录另建数据副本。

需要迁移时，请整体复制便携版程序文件夹和用户选择的数据文件夹。请勿单独移动数据文件夹内部的数据库或附件。账号密码按用户要求以明文保存在本地数据库中，请妥善保管数据文件夹，不要将其发送给无关人员。

## 功能

- 期刊 XLSX 导入、组合筛选、Enter 快捷查询、修改和三代备份；
- 论文及自定义附件可通过按钮或从资源管理器拖入；受管文件保留真实文件名（重名自动追加序号）；
- 附件支持打开、在文件夹中选中和修改真实文件名，列表始终显示数据目录中的实际名称；
- 投稿期刊历史、自动记录时间、状态纪要及不可覆盖的版本历史；
- 论文详情将投稿期刊历史与状态纪要合并显示：下拉切换期刊，当前状态唯一，纪要按新到旧排列；
- 论文列表默认只显示标题，展开后显示最近一次投稿期刊、彩色状态、附件数、投稿记录数和创建时间；
- 右上角可导出/导入三个业务板块的专用 `.psmdata` 数据包，包含受管附件和跨板块关联；
- 导入按名称合并，同名记录采用导入包内容，本地未冲突记录保留，导入前自动备份数据库；
- 作者及多个邮箱管理；
- 从期刊库或自定义创建、删除投稿栏目，管理链接和多组账号/密码；
- 从期刊数据库新建投稿栏目时可按期刊名称或 ISSN 搜索；
- 论文与期刊栏目双向关联和跳转；
- 论文投稿状态与期刊栏目的关联论文实时双向同步；任一侧新增或取消关联后另一侧立即更新；
- 数据库期刊栏目实时显示期刊库的最新资料；
- 投稿账号密码按用户要求作为本地明文记录保存。
- 投稿账号密码在列表和编辑窗口中明文显示，可选中后使用 Ctrl+C 复制。

## 开发与验证

```powershell
dotnet build PaperSubmissionManager\PaperSubmissionManager.csproj
dotnet run --project PaperSubmissionManager.Tests\PaperSubmissionManager.Tests.csproj -- "$PWD"
```

技术栈：.NET 9 WPF、SQLite、ClosedXML。

发布便携版时使用 `Portable` 发布配置。该配置为自包含多文件发布，不依赖目标电脑预装 .NET，也不使用会向系统临时目录释放运行组件的单文件自解压模式。
